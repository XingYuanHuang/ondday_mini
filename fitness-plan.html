哑铃俯身划船怎么做（背部唯一训练动作，必做！）
  1. 左手左膝撑在椅子/沙发上，右手持2kg哑铃
  2. 背部挺直，不要弓背，身体前倾约45度
  3. 右手拉哑铃到腰侧，手肘贴近身体
  4. 顶峰停1秒，感受背部收紧，缓慢放下
  5. 15个换边，每侧4组
  • 2kg轻 → 每组做15-20个，一样有效
  • 觉得轻松后 → 换4kg或6kg哑铃
  • 全程保持背部挺直，不要弓背
臀桥怎么做（超简单，4步）
  1. 仰面躺下，膝盖弯曲，脚踩地，脚跟靠近臀部
  2. 脚跟发力，屁股往上顶，身体从肩到膝成一条直线
  3. 最高点停2秒，感受屁股夹紧
  4. 慢慢放下，屁股轻触地面再顶起，不要完全放松
为什么要练背和臀？
久坐10小时本身就让背弱胸紧，只练胸（俯卧撑/波比）不练背会加重圆肩驼背。哑铃划船补背部，臀桥补大腿后侧和臀部，两大缺口补上体态才好看。

休息日 · 主动恢复（周二/四/日）

不训练，但不建议躺着不动。10-15分钟轻度活动，帮身体恢复更好。

项目时长说明
散步10-15分钟午饭后或晚饭后，刚好算NEAT
拉伸5分钟以下4个动作，每个保持20-30秒
4个拉伸动作
  • 站立体前屈：膝盖微曲，手尽量触地 → 拉大腿后侧
  • 弓步压髋：前腿90度，后腿膝盖着地，重心前压 → 拉髋屈肌
  • 胸部门框拉伸：手臂抵门框，身体前倾 → 拉胸肩，缓解驼背
  • 股四头肌拉伸：单脚站立，手拉脚踝向臀部 → 拉大腿前侧
休息日不要做：跳绳/波比/深蹲/跑步/骑车。休息日的心肺负荷会拖慢恢复。肌肉是在休息时生长的。
肌肉酸痛应对
方法怎么做效果
热敷热水澡/热水冲酸痛部位5-10分钟促进血液循环，加速恢复
轻度活动酸痛部位慢走10-15分钟动起来比不动恢复快

哪些酸痛要练，哪些要停？
  • 肌肉酸但不影响活动 → 正常练，热身后酸感会减轻
  • 关节痛（膝盖/脚踝/肩膀） → 停止该动作，换替代，这是受伤信号
  • 酸到蹲不下/抬不起手 → 当天改纯跳绳有氧，不做力量，缓1-2天
  • 小腿前侧疼 → 休息2-3天只散步+拉伸，胫骨前肌炎症，跳绳初期高发
酸痛时间线
  • 训练后第1天：轻微酸 → 正常，拉伸+热水澡
  • 训练后第2天：最酸 → 散步+拉伸，正好是休息日
  • 训练后第3天：减轻 → 适度训练，热身后会缓解，这天最关键，别放弃
  • 第2周起：只在训练后有轻微酸 → 基本适应
